# KEngine

## How to build

If you just want to update the submodules, simply run update_submodules.bat on Windows (or update_submodules.sh on Linux).

If it is your first time building the Engine, you need to run init_slang.bat on Windows (or init_slag.sh on Linux).

If you are on Windows, it is really important that you run the init_slang script in the x64 Visual Studio Developper Command Prompt run AS ADMINISTRATOR.
